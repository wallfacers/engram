### Findings

- **[BLOCKER] F1 — SC-004's operational definition is self-defeating: the cohort is defined as gold-absent while success is defined with a gold-overlap predicate, so the criterion cannot fail.** Population = "金块不存在的题目" (spec.md:128), yet the definition is "空注操作定义 = 展示命中为空（hits 为空或全部条目与 gold 无重叠）" (spec.md:128, quickstart.md:49). With no gold for the cohort, the overlap predicate is either undefined (the harness's own recall ruler returns `gradeable=false` when a QA carries no parseable `D<session>:<dialog>` refs — coverage.go:19-22) or vacuously true, so "全部条目与 gold 无重叠" is satisfied by any hit set. Under the OR, *every* question counts as an empty injection ⇒ rate ≡ 1 for both arms ⇒ `D ≥ C` cannot fail. Under the alternative reading (hits-empty only), C is pure truncation of a populated RRF pool and is ~never empty ⇒ `D ≥ C` is again trivially true. Objective 2's "empty-injection rate on gold-absent questions (D-noRelax) ≥ C" — the headline honest-empty proof — is therefore unattestable. Smallest fix: define the metric as `hits == []` alone (or specify the gold source + overlap function and drop the OR), and add an absolute floor for D (e.g. D's honest-empty rate on the declared category-5 block ≥ X) since a comparison against a structurally constant C cannot discriminate.
