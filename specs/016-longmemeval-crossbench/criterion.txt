定义（全部基于 S 臂，逐题精确证据覆盖率分桶后计算）：

- 全覆盖桶：逐题精确证据覆盖率 == 1.0
- 部分覆盖桶：0 < 逐题精确证据覆盖率 < 1.0
- 零覆盖桶：逐题精确证据覆盖率 == 0
- 条件增益 = 全覆盖桶正确率 − 零覆盖桶正确率（单位 pp）
- 检索侧当量 = 零覆盖题数 × 条件增益
- 答题侧当量 = 全覆盖桶中仍然答错的题数

结论三选一：

- 复现：条件增益 ∈ [20, 50] pp 且 检索侧当量 < 答题侧当量
- 证伪：条件增益 > 60 pp 或 检索侧当量 > 答题侧当量
- 无法判定：以上两者均不成立

附加纪律：

- 任一桶的题数 n < 20 时，该桶标记为不可判，不得以其点估计支撑结论
- 边界值按闭区间字面判定，不得四舍五入到任一侧
- 条件增益落在 (50, 60] 区间时为「无法判定」，这是有意留下的空档，不得填补
