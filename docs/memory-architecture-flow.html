05 · 写入时冗余抑制

重复的投影，写不进去 实验杠杆 · 默认关

新增事实投影前做字符相似度（trigram Jaccard，阈值 0.7）冗余判定，抑制重复投影—— Evidence 无损保留。矛盾事实绝不抑制（供时间校正）。实测：21,860 次判定仅 20 次抑制 → 保持默认关。

11 · 宪法保证

为什么可以信任这条流水线

五条不可谈判的约束，横贯写与读。

🔒
无损 Evidence Ledger
原文 append-only、永不覆盖；普通删除 = 可恢复 tombstone，显式隐私 = purge 清原文。
🧊
Namespace 隔离
一 namespace 一 DB，路径逃逸为 0；跨命名空间读取默认禁止。
🛰️
离线可降级
embedding / LLM / reranker 皆是可选 sidecar；缺信号逐路退出，本地写入与搜索照常。
🧪
实验杠杆默认关
冗余抑制 / 邻居扩展 / reranker 全部默认关；只有配对消融正向才谈进默认路径。
📊
Eval 回归门
任何触及检索 / 抽取 / 存储 / embedding 的变更 MUST 跑双基准配对消融，不得回归基线。
⚖️
诚实规模
单用户 ~100k 记忆类；ANN / 百万 token / 集群是明确未来工作，不是隐含承诺。
