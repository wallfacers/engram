# SaaS 习惯记忆探索

这是未立项、未实现的 proposed 探索，不能作为当前能力或路线承诺。当前已交付范围请看[当前能力边界](../capabilities.md)。

## 探索问题

若面向 SaaS 的记忆要归纳稳定偏好或工作习惯，必须先证明它能在用户授权、可解释、可撤销和跨租户隔离下提供净价值。它不能通过隐式收集聊天、模糊身份边界或把一次性行为误写为长期习惯来实现。

## 启动门与停止条件

启动前需要书面数据边界、用户控制面、撤回语义、离线评测和误归纳风险度量。若无法在这些条件下定义可验证收益，或价值只能依赖不透明的跨租户数据聚合，则停止探索而不进入实现。
