# LoCoMo 91.10% 复现：3-rep clean majority 独立重判

**日期**: 2026-08-12 · **宪法 IV**: 已验证基线复现 · **状态**: ✅ 复现一致

## 目标

独立复现 LoCoMo 90+ 已验证分数 **91.10%（1403/1540）**，确认其不是单批 judge 伪影，而是稳定、可重判的结果。

## 方法

- **数据源**: 云机 `eval-backup-20260811-144859/topk-full/tk150-full3/run-{1,2,3}/results-hybrid.jsonl`
  （2026-08-11 的 LoCoMo 全量 3-rep，每 run 1540 题，top-k 150 / chunk-quota 12 / thinking 开）
- **重判**: 本地 `rejudge_locomo.py`（`~/.claude/session-scratch/lme-rejudge/`）
  - flash judge（`deepseek-v4-flash`，thinking disabled，temp=0，max_tokens 512）
  - judge prompt 与 harness `judgeMem0AlignedSystemPrompt` 逐字一致，anthropic `/v1/messages`
  - **raw** = 完整 pred；**clean** = `extractFinalAnswer` 剥离 thinking（与 runner.go 一致）
  - 6 个独立判定文件（run-1/2/3 × raw/clean），每题真正 3 次判定
  - **3-rep majority**：每题 3 次判定取多数

## 结论

1. **91.10% 是真实可复现的**：1403/1540 与当初独立重算完全一致。LoCoMo 90+ 站得住。
2. **judge 作弊量跨数据集统一再确认**：clean−raw = −1.56pp（LoCoMo）≈ −1.2~1.5pp（LME baseline）。judge 从 thinking 前导读候选是稳定现象，非单批噪声。
3. **open-domain 是短板**（68.8%），与 LoCoMo 错题画像一致（open-domain 翻转）——90+ 已过，但类别差距仍存在。
4. **方法修正**：top-k150 大上下文 + Qwen 单 answer 请求 >3min（perCallTimeout），在线 1-rep 复现不可行且非当初口径。90+ 复现必须走离线 3-rep + clean 重判，近零成本。

## 诚实边界

- 重判为单批 flash judge（temp=0 仍带 ±1pp 模型噪声，跨批 ±2.5pp）。
- 3-rep majority 是 top-k150+thinking 组合的稳定分；切换 top-k / thinking 会改变基线，不得外推。
